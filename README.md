# DavidSoft Writer

A free desktop word processor for Windows that opens, edits and saves Word documents (`.docx`) — no
subscription needed.

## Download

Get the latest version from the **[Releases](../../releases/latest)** page:

| File | What it is |
| --- | --- |
| `DavidSoft.Writer_<version>_arm64-setup.exe` | Installer (recommended). Installs for your user account only, no admin rights needed. |
| `DavidSoft.Writer_<version>_arm64_en-US.msi` | Windows Installer package, for installing with IT tools or for all users. |

> **Note:** the current builds are for **Windows on ARM (ARM64)** PCs, such as Snapdragon laptops.
> Builds for regular Intel/AMD (x64) PCs are planned.

### Installing

1. Download the `-setup.exe` file and double-click it.
2. Windows may show **"Windows protected your PC"** because the installer isn't code-signed yet.
   Click **More info → Run anyway**.
3. DavidSoft Writer appears in the Start menu. Word documents (`.docx`, `.doc`, `.odt`, `.rtf`) can be
   opened with it from File Explorer (right-click → Open with).

Requires Windows 10 or 11 with the Microsoft Edge WebView2 runtime (already included in Windows 11).

### Uninstalling

Settings → Apps → Installed apps → DavidSoft Writer → Uninstall.

## Features

- **Word documents**: opens and saves `.docx`, keeping what it doesn't edit (charts, shapes, equations,
  themes) untouched. Also opens `.doc`, `.odt` and `.rtf`.
- **Formatting**: every installed font, sizes, colours and highlights, styles (Normal, Title, Headings,
  Quote and your own), bullet and numbering styles, indents, spacing, tab stops.
- **Pages**: page-by-page view, page size, orientation and margins, rulers you can drag, headers and footers
  with page numbers, footnotes, table of contents.
- **Tables and pictures**: merge/split cells, shading, borders; resize, crop and wrap pictures.
- **Reviewing**: comments with replies, tracked changes from Word (accept/reject), find and replace.
- **Spell check** as you type (English US/UK) with suggestions.
- **Navigation pane** showing the document's headings.
- **Print preview** with page ranges, and **Export to PDF**.
- **Never lose work**: crash recovery and optional AutoSave.
